# 🌙 Mystic AI Bot - Таролог, Астролог, Рунолог

AI-агент бот для эзотерических консультаций: расклады Таро, астрологические прогнозы и рунические расклады.

## ✨ Возможности

- 🎴 **Таро** - различные типы раскладов (одна карта, три карты, кельтский крест)
- ⭐ **Астрология** - анализ натальной карты, прогнозы по вопросам
- ᚠ **Руны** - рунические расклады (Старший Футарк)
- 💬 **Общие консультации** - ответы на эзотерические вопросы

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd mystic_bot
pip install -r requirements.txt
```

### 2. Настройка

Скопируйте файл `.env.example` в `.env` и заполните своими данными:

```bash
cp .env.example .env
```

Отредактируйте `.env`:
- `TELEGRAM_BOT_TOKEN` - токен вашего Telegram бота (получить у @BotFather)
- `AI_API_KEY` - API ключ для доступа к LLM (OpenAI или совместимый)
- `AI_API_BASE_URL` - URL API (по умолчанию OpenAI)
- `AI_MODEL` - модель для генерации ответов

### 3. Запуск бота

```bash
python main.py
```

## 🛠 Расширение и доработка

### Добавление новых раскладов

1. Откройте `services/ai_service.py`
2. Добавьте новый метод с промптом для конкретного расклада
3. В `handlers/bot_handlers.py` добавьте обработчик команды

### Пример добавления нового типа расклада Таро

```python
# В ai_service.py
def get_love_tarot_reading(self, question: str) -> str:
    system_prompt = """Ты специалист по любовным раскладам Таро..."""
    # ... реализация
```

### Интеграция с другими AI провайдерами

Бот использует OpenAI-compatible API, поэтому легко подключить:
- Google Gemini
- Anthropic Claude
- Локальные модели (Ollama, LM Studio)
- Российские модели (GigaChat, YandexGPT)

Просто измените `AI_API_BASE_URL` и `AI_MODEL` в `.env`.
