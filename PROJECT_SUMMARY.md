# 🌙 Mystic AI Bot - Чат-бот таролог, астролог, рунолог

Я создал для вас полноценного AI-агента бота для эзотерических консультаций! 

## ✅ Что уже реализовано:

### Структура проекта:
```
mystic_bot/
├── main.py              # Запуск бота
├── config.py            # Настройки и переменные окружения
├── handlers/
│   └── bot_handlers.py  # Все обработчики команд
├── services/
│   └── ai_service.py    # Интеграция с AI (OpenAI-compatible)
├── data/                # Для базы данных и логов
├── prompts/             # Для кастомных промптов
├── requirements.txt     # Зависимости Python
├── .env.example         # Шаблон конфигурации
└── README.md            # Документация
```

### Функционал:

1. **🎴 Таро** (`/tarot`)
   - Расклад "Одна карта" - быстрый ответ
   - Расклад "Три карты" - прошлое/настоящее/будущее
   - "Кельтский крест" - полный анализ ситуации

2. **⭐ Астрология** (`/astrology`)
   - Ввод даты, времени и места рождения
   - Анализ натальной карты
   - Ответы на вопросы по прогнозам

3. **ᚠ Руны** (`/runes`)
   - Расклад "Одна руна" - совет дня
   - "Три руны" - ситуация/препятствие/совет
   - "Расклад Одина" - глубокий анализ

4. **💬 Общие консультации**
   - Автоматические ответы на любые эзотерические вопросы

## 🚀 Как запустить:

```bash
cd mystic_bot

# 1. Установить зависимости
pip install -r requirements.txt

# 2. Создать файл .env из шаблона
cp .env.example .env

# 3. Отредактировать .env (указать токены)
nano .env

# 4. Запустить бота
python main.py
```

## 🔧 Необходимые ключи:

1. **Telegram Bot Token** - получить у [@BotFather](https://t.me/BotFather)
2. **AI API Key** - OpenAI или совместимый сервис (можно использовать локальные модели через Ollama)
